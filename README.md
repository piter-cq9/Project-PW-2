# Boleta de Consumo (C#)

Programa de consola en C# que calcula el consumo de un cliente y muestra una boleta.

Operaciones usadas:
- Multiplicacion: precio x cantidad
- Suma: total del consumo
- Resta: total - descuento
- Division: total a pagar / numero de personas

## Requisitos
- .NET SDK (https://dotnet.microsoft.com/download)

## Ejecutar
```
dotnet run
```
